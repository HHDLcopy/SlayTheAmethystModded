# [#](#history) history

打印命令历史。

提示

历史指令会通过一个名叫 history 的文件持久化，所以 history 指令可以查看当前 arthas 服务器的所有历史命令，而不仅只是当前次会话使用过的命令。

## [#](#参数说明) 参数说明

参数名称

参数说明

\[c:\]

清空历史指令

\[n:\]

显示最近执行的 n 条指令

## [#](#使用参考) 使用参考

```
#查看最近执行的3条指令
$ history 3
  269  thread
  270  cls
  271  history 3
```

```
 #清空指令
 $ history -c
 $ history 3
  1  history 3
```
